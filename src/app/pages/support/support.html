Support

Job Finder is a local search and tracking app. Use this page to unstick listings, applications, and the API. Employer questions belong on the posting you opened with Apply.

Jobs will not load

The web app on port 4200 needs the API on 127.0.0.1:8000. From the project folder run npm run start:all, wait until both web and api are ready, then click Refresh on Jobs.

Too few listings, or only one board

Click Clear on Jobs, then Refresh. Site chips and Remote / Full-time / US all stack. Search Settings control the query itself — edit titles, skills, and location there, save, then Refresh again.

I applied but the count did not change

Apply opens the real posting. When you return to Applications, choose Yes, I applied. That moves the role to Applied and keeps it off Jobs after Refresh.

I do not want a role anymore

On Applications use Return to Jobs to put it back in the search. Remove on Jobs hides that listing. Hidden and applied roles stay off the Jobs list after Refresh.

Profile or applications disappeared

Registered-account data is stored in the local SQLite database and linked to your account, so your profile, search settings, and applications are not tied to one browser origin. Guest data is local-only; another browser, a private window, or clearing site data starts a new Guest session. Use the same account credentials when you sign in.
